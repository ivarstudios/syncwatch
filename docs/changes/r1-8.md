## 1. Group C documentation corrections

### W-063 (medium): nginx snippet `Host $host` stops the login behind nginx on a non-default port
- **Root cause.** `checkCSRF` (`internal/web/auth.go:174`) needs `Origin` to end with `"://" + r.Host`. nginx `$host` drops the port, the browser's `Origin` has it, so every POST (the login included, `server.go:476`) gets 403 "cross-origin request refused".
- **Changed.** README "Behind a reverse proxy": `proxy_set_header Host $http_host;` with the comment that `$host` removes the port; the text says the Host must keep the port and that the login and each save fail with a wrong Host. The known-name sentence (`public_url` / `SYNCWATCH_TLS_HOSTS`, r0-e) stays.

### W-064 (medium): a bootstrap file with an error stops the start; the scrub rewrites the file
- **Root cause.** `LoadConfig` (`internal/app/app.go:96-103`) returns the `ParseYAML` error (yaml decode error with the line, or `Validate` with the key), so `serve` exits 1 and `restart: unless-stopped` loops. `scrubBootstrap` (`bootstrap.go:87`) re-encodes the yaml.Node tree: comments stay, the format can change.
- **Changed.** README "Bootstrap file": the scrub sentence now says syncwatch writes the file again (comments stay, the format can change); new paragraph: a file with an error stops the start (examples), the log names the line or the key, correct or remove the file, the restart loop.
